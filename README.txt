サイバー速報ウォッチ（Androidタブレット向け試作品）

内容
- index.html : ニュース一覧ページ
- Google ニュースの検索RSSを4種類（不正アクセス、情報漏洩、サイバー攻撃、個人情報漏えい）から取得
- キーワード絞り込み、期間絞り込み、更新、記事リンクに対応

重要な制約
- RSSをブラウザから読み込めるJSONに変換するため、外部サービス api.rss2json.com を利用します。無料サービスの制限・障害・仕様変更で取得できなくなる場合があります。
- index.htmlを端末に保存してファイルアプリから直接開く方式では、ブラウザの制約により取得できないことがあります。安定利用するには、HTTPS対応の静的ホスティング（例：GitHub Pages）に配置してURLから開いてください。
- これは試作品であり、ニュースの網羅性・速報性・正確性を保証しません。重大なインシデントは公式発表や報道元で確認してください。

Androidでの使い方（簡易）
1. ZIPを解凍し、index.htmlを確認します。
2. 安定運用する場合は、index.htmlをHTTPSのWebホスティングにアップロードします。
3. AndroidタブレットのChromeでそのURLを開き、メニュー（︙）→「ホーム画面に追加」または「インストール」を選びます。
4. 画面の「更新」でニュースを再取得します。

改善候補
- 定期更新、重要度分類、既読管理、通知、公式機関のRSS追加には、ホスティングとバックエンドを追加する構成がおすすめです。
